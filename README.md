# SK Builders — Static Site

This repository contains a single-page static website for SK Builders (electrical, plumbing, CCTV, fire safety).

Local preview

1. Open `index.html` in your browser (double-click or use `Start-Process index.html` on Windows PowerShell).

Deploy options

- Netlify (recommended): connect your GitHub repo and enable automatic deploys.
- Vercel: `vercel` CLI or connect GitHub for CI/CD.
- GitHub Pages: push to a repo and enable Pages from the `main` branch root.
